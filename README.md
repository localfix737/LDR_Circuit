# LDR Automatic Light Switch Circuit

A circuit that automatically turns a light ON in the dark 
and OFF in the light, using an LDR sensor and a relay.

## Tools Used
- Proteus (simulation)
- Darlington pair transistors (2N2222A)
- 5V relay, 1N4007 flyback diode

## How it works
The LDR detects light levels. When it gets dark, 
the transistors activate the relay, switching the light ON.
